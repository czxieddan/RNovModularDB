# Source and History

- Canonical repository: https://github.com/czxieddan/RNovModularDB
- Complete repository and history: `git clone https://github.com/czxieddan/RNovModularDB.git`
- Exact dependency versions: `Cargo.lock`
- Build: `cargo build --workspace --locked`
- Test: `cargo test --workspace --locked`
- Release mapping: repository tags and release records identify published revisions; use the referenced commit when no tag is present

The repository contains the source, build configuration, dependency lock file, and modification history required to reproduce the corresponding revision. No private credentials or production data are required for a normal build.
